About SamparkPro

SamparkPro is a modern and secure contact management web application designed to help users efficiently manage their personal and professional contacts in one place.

Built using Spring Boot and Thymeleaf, SamparkPro ensures high performance, strong security, and a seamless user experience across devices.

✔ Secure login with Spring Security

✔ Add, update and delete contacts easily

✔ Cloud-based image storage

✔ Fast and responsive UI

✔ User-friendly dashboard
